# Goalie Mom

Public issue tracker for the Goalie Mom iOS app.

This repository is for bug reports, feature requests, and general feedback. The source code for the app lives in a private repository and is not available here.

## How to report an issue

1. Check existing [Issues](https://github.com/RichRoCode/goalie-mom-feedback/issues) to see if your request or bug has already been reported.
2. Click **New issue**.
3. Choose a title and describe the problem or idea clearly.
4. Include:
   - App version (Settings → Help & Support shows it)
   - iOS version and device
   - Steps to reproduce (for bugs)
   - Screenshots if helpful

## What this repo is for

- Bug reports
- Feature requests
- Usability feedback
- Questions about the app

## What this repo is not for

- Source code (private)
- Account or billing support — use the in-app **Email Support** button or visit [goaliemom.app/support](https://www.goaliemom.app/support)
- Documentation — see [goaliemom.app/docs](https://www.goaliemom.app/docs)
